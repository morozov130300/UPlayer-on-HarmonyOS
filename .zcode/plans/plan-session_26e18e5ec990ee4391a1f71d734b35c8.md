# 空库时引导内置「模拟歌曲行」真手势演示

## 目标
曲库为空时，「左滑删除 / 长按管理」两步不再指向导入入口叫用户去导入，而是由引导浮层自己渲染一条「示例歌曲」假行，用户可在其上真实左滑（露出红色删除按钮）、长按（弹提示气泡），先体验手势；导入真实歌曲后同样操作。

## 改动

### 1. `CoachMarkOverlay.ets`
- `CoachStep` 新增 `demoSong: boolean = false` 字段；`demoSong=true` 的步骤不依赖宿主锚点（targetId 留空走默认高亮带）。
- 高亮带内渲染模拟歌曲行（仅 demoSong 步骤）：
  - 底层右端：红色圆角删除按钮区（`ic_public_delete` 图标 + 「删除」），被前景遮挡
  - 前景：圆角专辑占位（`ic_public_music`）+ 「示例歌曲」+ 副标题「演示用，不会真的删除」，宽=高亮带宽、高约 56、垂直居中于高亮带
  - 手势：`PanGesture(Horizontal)` 驱动 translate.x（夹在 [-80, 0]），松手位移过半吸附到露出删除按钮位、否则弹回 0（带动画）；长按步骤挂 `LongPressGesture`，触发时行上方弹小气泡「长按后松手进入批量管理（演示）」，1.5s 自动消失
  - 模拟行浮在挖孔与描边框之上，手势由行消费，点行外任意处照旧进下一步
- 复用现有插值动画与卡片放置逻辑，不动挖孔 Canvas。

### 2. `HomeContent.ets` — `buildHomeCoachSteps()`
- 空库步骤改为：`[左滑演示(demoSong), 长按演示(demoSong), 排序胶囊, 平铺胶囊]`
- 删除「添加本地歌曲」导入步骤（不再叫用户去导入）；演示步骤文案注明「导入歌曲后对真实歌曲同样操作」。
- `coach_home_empty_hint` 的 .id 保留（空态 UI 本身不动）。

### 3. `PlaylistContent.ets`
- 空文件夹 else 分支（「暂无歌单，点击添加歌曲」区域，约 L783-798）补 `.id('coach_folder_grid')`，修掉无文件夹时引导框掉到屏幕中部的问题。
